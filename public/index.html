# Кошелёк Адрес Где деньги Итого

Адреса

По одному на строку. Можно с названием: 0xabc… Основной или Основной, 0xabc…

Сид-фразы и приватные ключи

Обрабатываются только в этом окне браузера. Из сид-фразы здесь же получаются адреса, и только они уходят на локальный сервер и сохраняются. Сама фраза никуда не отправляется и не сохраняется, поле очищается сразу.

Одна сид-фраза или приватный ключ на строку. Можно подписать: Метамаск старый: word1 word2 …

Перед тем как собирать: перевод со многих кошельков на один адрес навсегда связывает их в блокчейне — антисибил-фильтры аирдропов увидят их как одного человека. И адрес получателя проверяй по символам: транзакции не отменить. Ключи и сиды вставляются только в эту вкладку, хранятся в её памяти и не уходят на локальный сервер и на диск.

1. Куда собрать

2. Ключи для подписи

Только в этой вкладке. Сиды и ключи превращаются в кошельки прямо здесь; в памяти страницы остаются только те, чьи адреса есть в плане, остальное сразу выбрасывается. На сервер и на диск ничего не пишется. Ключи забываются после отправки, через 20 минут, по кнопке и при закрытии вкладки.

3. План (пробный прогон)

Балансы и газ — живые, с RPC прямо сейчас; цены — из последнего скана. «Газ» — резерв по максимальной цене, по факту обычно уходит меньше, поэтому нативной монеты придёт чуть больше плана. Кошелькам без газа газ довозит автобус, если он включён.

4. Отправка

По одной транзакции за раз в каждой сети (с ожиданием подтверждения), сети идут параллельно. Сначала токены, потом остаток нативной монеты.

Alchemy API key

Бесплатный ключ: dashboard.alchemy.com → Apps → твоё приложение → API Key. Хранится только локально в data/config.json.

Порог «мелочи»

Кошельки и монеты дешевле этой суммы считаются пустыми.

Сети

Если какой-то сети нет в твоём Alchemy-приложении, включи её в дашборде Alchemy (Apps → Networks) или просто выключи здесь.

Скрытые монеты

Монеты, которые ты скрыл кнопкой ✕ в деталях кошелька (например, спам с фейковой ценой).

Начать с нуля

Удаляет весь список кошельков и результаты сканов, нумерация снова начнётся с #1. Ключ Alchemy, сети и скрытые монеты остаются. Сами кошельки и деньги на них это не затрагивает.
